# Field Radar: public demo

A map-first field sales app for regional sales managers: which outlets the reps covered, which they didn't visit in time,
alerts such as duplicate visits, an Inbox to decide on them, and writeback (ask a rep, request a CRM change).

**Open the demo:** https://witttwo.github.io/field-radar-demo/

This is a static build with sample data only. It has no sign-in and no connection to any backend.

- Reps, visits, sales, shelf audits and alerts are made up.
- Outlet positions come from open data. Shop names are fictional and street addresses are removed, so no real shop is shown with made-up results.
- Anything you change, such as a question to a rep, a decision or a CRM request, stays in your own browser.
